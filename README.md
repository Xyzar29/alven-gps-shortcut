An entry for the [make.fun](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9) bounty **"The GPS Swears It Was a Shortcut"**.

`main.ts` writes the GPS's one-line excuse for sending the driver down the wrong road to `/output/entry.txt` — smug, defensive, blaming the map, with a lake that was supposedly a shortcut and a wedding as the punchline. One line, 118 characters, no setup, no dialogue tags.

Run it with Node 22+:

```sh
node main.ts
```
